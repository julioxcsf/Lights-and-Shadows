# **3D Object Renderer**  

![Renderização 1](https://github.com/user-attachments/assets/7bcb7b35-0611-4afb-a9dd-d7af0b85d1fc)  

## **Descrição**  
Este é um **gerador de objetos 3D sem colisão** desenvolvido com OpenGL.  
Cada objeto pode ser manipulado individualmente, permitindo alterações na **posição, rotação e escala**.  

A renderização utiliza o **modelo de iluminação Phong**, proporcionando uma aparência mais realista.  
A geração de sombras é implementada através do **Z-buffer**, garantindo profundidade e realismo na cena.  

---

## **Principais Funcionalidades**  
✔️ Manipulação de objetos 3D (**translação, rotação e escala**)  
✔️ Iluminação baseada no modelo **Phong**  
✔️ Sombras implementadas com **Z-buffer**  
✔️ Renderização otimizada com **OpenGL**  
✔️ Botão de reset para **Shaders**
